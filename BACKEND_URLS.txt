## Frontend Backend URL Configuration

The frontend now supports runtime configuration WITHOUT rebuilding the Docker image.

### Option 1: Update Helm Values (Recommended)
```yaml
# values.yaml
frontend:
  runtimeConfig:
    backendUrl: "http://af3615e06391145bc88022ac024a36ca-bd296660cda3522f.elb.us-west-2.amazonaws.com"
```
Then: `helm upgrade <release> ./deploy/helm/aiq-aira`

### Option 2: Edit ConfigMap Directly
```bash
kubectl edit configmap <release>-frontend-config -n <namespace>
kubectl rollout restart deployment/<release>-aira-frontend -n <namespace>
```

### Option 3: Rebuild Image (Legacy)
```bash
./infrastructure/kubernetes/redeploy-frontend.sh
```

See frontend/README.md for full documentation.
